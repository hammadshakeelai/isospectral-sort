Core Mathematics

The 4 Paradigms of Pure-Math Sorting

Connecting differential geometry, integrable Hamiltonian dynamics, fluid optimal transport, and tropical soliton mechanics.

Lie Bracket Gradient Flow

Roger Brockett Flow (1991)

Steepest ascent flow of $\Phi(H) = \mathrm{Tr}(HN)$ on the adjoint orbit $\mathcal{O}(H_0)$ of $\mathrm{SO}(n)$. Converges strictly to the unique sorted diagonal matrix via Hardy-Littlewood-Pólya rearrangement inequality.

$$\frac{dH}{dt} = [H, [H, N]] = [[N, H], H]$$
▶ Run in VS Code Lab Harvard Univ / LAA
Integrable Hamiltonian Scattering

Jürgen Moser Toda Lattice (1975)

Exact Lax equation $\dot{L} = [B, L]$ for $n$ particles interacting via exponential repulsive springs. As $t \to +\infty$, off-diagonal couplings decay exponentially and particles decouple in strictly sorted velocities.

$$\frac{dL}{dt} = [B, L], \quad \lim_{t \to \infty} L(t) = \mathrm{diag}(\lambda_1 < \dots < \lambda_n)$$
▶ Run in VS Code Lab Courant Institute / Springer
Thermodynamic Measure Flow

Monge-Brenier Optimal Transport (1991)

Brenier's Theorem guarantees that in 1D under quadratic cost, the unique optimal transport map $T = \nabla \Phi$ pushing empirical measure to uniform ranks is the monotone sorting rearrangement. Solved via Sinkhorn-Knopp flow.

$$\min_{P \in \mathcal{U}} \langle P, C \rangle - \varepsilon H(P), \quad P^* = \mathrm{diag}(u) K \mathrm{diag}(v)$$
▶ Run in VS Code Lab INRIA / ARMA
Tropical Soliton Automaton

Takahashi-Satsuma Box-Ball (1990)

Ultradiscretization of the nonlinear KdV equation. Soliton pulses of length $L$ advance with velocity $v(L) = L$ through non-destructive elastic collisions, spontaneously decomposing disordered states into sorted soliton trains.

$$v(L) = L, \quad \Delta x = 2 \min(L_1, L_2)$$
